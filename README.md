# 📚 Biblioteca Pessoal

Um sistema simples de gerenciamento de livros, desenvolvido em Java. Para praticar conceitos de Programação Orientada a Objetos (POO), estruturas de dados e lógica de programação.

## ✨ Funcionalidades

* 👤 Cadastro de usuário
* 🔒 Validação de usuário e senha
* 📖 Cadastro de livros
* 📋 Listagem de livros
* 🗑️ Remoção de livros
* ✅ Marcar livro como lido
* 📊 Estatísticas de leitura
* ⚠️ Tratamento de entradas inválidas

* Criar e organizar um projeto Java em múltiplos pacotes.

* Desenvolver menus interativos utilizando switch.
